**Список больших задач**
1. Интеграция АБС с Kafka для автоматизированной daily публикации ставок
2. Улучшить систему кол-центра: добавить возможность получать ставки из потока данных
3. Создать отдельный сервис для публикации ставок: реализовать получение сообщений из потока данных
4. Реализовать формирование файлов с актуальными ставками на текущий день
5. Настроить интеграцию с облачным хранилищем Yandex: обеспечить ежедневную публикацию ставок в облако
6. Организовать ежедневную рассылку писем со ссылкой на актуальные ставки в облаке Yandex
7. Реализовать мониторинг и алертинг: настроить оповещения о сбоях в процессе публикации ставок
